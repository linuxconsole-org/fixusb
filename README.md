# Fixusb

Scripts that can be safely used on fixusb folder, when booting with fixusb option

##autologin-lxdm  

Enable autologin when starting LXDM

##autostart-lxdm  

Force starting LXDM

##create-root  

Create root account

##create-users 

Create users accont

##flatpak-disk  

Enable persitant Flatpak on USB disk

##lightdm

Enable Lightdm (To Fix : Cannot start session)
